# 법인설립의 모든 것

원본: https://www.ceopartners.info/
분석·저장 날짜: 2026-10-20

## 열기
`index.html`을 브라우저로 열면 됩니다. `conversion.html`은 법인 전환 페이지입니다.
로컬 서버를 사용하려면 이 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 으로 접속하세요.

## 구현 범위
- 원본 공개 HTML/CSS의 배치, 색상, 문구, 이미지, 글꼴을 활용한 정적 화면 재현
- 메인 페이지 및 법인 전환 페이지, 섹션 이동, 외부 이용메뉴얼 링크
- 이미지와 글꼴 52개 로컬 저장, assets-manifest.json에 출처 기록
- 상담 버튼에 키보드로도 사용할 수 있는 입력창 연결. 입력은 브라우저 localStorage에만 저장되며 실제 접수가 아닙니다.

## 차이와 제한
원본 Wix 관리 시스템, 회원 기능, 실제 상담 접수·알림톡·서버 데이터 처리는 포함하지 않습니다. 상담창은 독립적으로 구현한 데모이며 원본 상담창과 동일하다고 검증하지 않았습니다. 대표홈페이지와 이용메뉴얼은 외부 사이트로 이동합니다. 원본 데스크톱 레이아웃을 보존한 자료로 모바일 전용 Wix 화면까지 동일하다고 보장하지 않습니다. 원본 서비스에 요청을 보내는 Wix 런타임 및 추적 스크립트는 제거했습니다.

상표·문구·사진 등 원본 콘텐츠는 해당 권리자에게 귀속됩니다. 공개 운영 전 사용할 브랜드·콘텐츠와 실제 접수 서비스를 준비하세요.
