## 열기
`index.html`을 브라우저로 열면 됩니다. `conversion.html`은 법인 전환 페이지입니다.
로컬 서버를 사용하려면 이 폴더에서 `python3 -m http.server 8000` 실행 후 http://localhost:8000 으로 접속하세요.

## 구현 범위
- 원본 공개 HTML/CSS의 배치, 색상, 문구, 이미지, 글꼴을 활용한 정적 화면 재현
- 메인 페이지 및 법인 전환 페이지, 섹션 이동, 외부 이용메뉴얼 링크
- 이미지와 글꼴 52개 로컬 저장, assets-manifest.json에 출처 기록
- 상담 버튼에 키보드로도 사용할 수 있는 입력창 연결. 입력은 서버 함수 `/api/consult`로 전송되어 Firestore에 저장됩니다(브라우저 localStorage 저장 없음). 2026-10-24 개편 내용은 아래 '상담 접수·개인정보' 참고.

## 차이와 제한
원본 Wix 관리 시스템, 회원 기능, 실제 상담 접수·알림톡·서버 데이터 처리는 포함하지 않습니다. 상담창은 독립적으로 구현한 데모이며 원본 상담창과 동일하다고 검증하지 않았습니다. 대표홈페이지와 이용메뉴얼은 외부 사이트로 이동합니다. 원본 데스크톱 레이아웃을 보존한 자료로 모바일 전용 Wix 화면까지 동일하다고 보장하지 않습니다. 원본 서비스에 요청을 보내는 Wix 런타임 및 추적 스크립트는 제거했습니다.

상표·문구·사진 등 원본 콘텐츠는 해당 권리자에게 귀속됩니다. 공개 운영 전 사용할 브랜드·콘텐츠와 실제 접수 서비스를 준비하세요.

## Vercel 배포

GitHub 저장소 `nicegrowth11-cloud/homepage_corp`를 Vercel에서 Import합니다.
- Root Directory: 저장소 루트 (`.`). 로컬 폴더 이름인 `ceopartners`를 입력하지 않습니다.
- Framework Preset: Other
- Build Command: `npm run build`
- Output Directory: `dist`
- Node.js: 24.x
- 환경 변수: 상담 접수 함수(`api/consult.js`)용. 아래 '상담 접수·개인정보' 참고.

`vercel.json`에 빌드·출력 설정을 저장했습니다. `node scripts/build.mjs`는 페이지에서 사용하는 파일만 dist에 복사하고 누락된 참조 파일이 있으면 실패합니다. 과거 분석 HTML, 미사용 이미지·글꼴은 공개 배포물에 포함하지 않습니다. GitHub 연결 후 main 브랜치를 업데이트하면 Vercel에서 새 프로덕션 배포가 시작됩니다.

현재 상담 폼은 브라우저 내 임시 저장 기능입니다. Vercel에 배포해도 실제 문의 전송으로 바뀌지 않습니다. 실제 접수를 사용하려면 Vercel Function과 저장소 또는 이메일 서비스를 별도 연결해야 합니다.

## 상담 접수·개인정보 (2026-10-24, revision-1023)
- `/privacy` 개인정보 처리방침 페이지 추가(참고용 초안, 법무 검토용 원문 마크다운을 문구 수정 없이 HTML로 변환). 모든 페이지 하단과 상담 폼 바로 아래에 링크.
- 상담 폼 동의 3항목(① 수집·이용 필수, ② 국외 이전 필수, ③ 광고성 정보 선택). 기본값은 모두 미체크이며 ①·② 체크 전에는 신청 버튼이 비활성화되고 서버도 거부합니다. 문구는 `consult-forms.json`의 `consents`(consentVersion v0.1).
- 서버 저장 레코드: consentPrivacy, consentOverseas, consentMarketing, consentAt, consentVersion.
- 서버 검증: Origin·Content-Type·8KB 크기 제한, 항목 화이트리스트·길이 제한, 허니팟, 3초 미만 제출 차단, 인스턴스별 IP 속도 제한, 주민등록번호·계좌번호 패턴 거부.
- Firestore 보안 규칙(`firestore.rules`): 클라이언트 읽기·쓰기 전면 거부(서버 서비스 계정만 기록).
- 필요한 Vercel 환경 변수: `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`(필수), `FIREBASE_DATABASE_ID`·`CONSULT_TOKEN_SECRET`·`CONSULT_ALLOWED_ORIGINS`(선택). 설정 전에는 함수가 503을 반환하고 폼에 '접수 일시 오류' 안내가 표시됩니다.
