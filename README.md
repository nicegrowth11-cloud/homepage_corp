# 법인설립의 모든 것

세무법인 BHL 강남지점의 법인 설립·전환 안내 홈페이지입니다.

- 공개 주소: https://homepage-corp.vercel.app/
- GitHub: https://github.com/nicegrowth11-cloud/homepage_corp
- 화면: `index.html` (설립 지원), `conversion.html` (법인 전환)
- 폰트: SUITE Variable 자체 제공. `assets/SUITE-LICENSE.txt`에 OFL 사용 허가 포함.

## 실행·배포

```sh
npm run build
python3 -m http.server 8000 --directory dist
```

Vercel은 저장소 루트에서 `npm run build`를 실행하고 `dist/`만 배포합니다. Node.js 24.x, Framework Other, 환경 변수는 필요하지 않습니다. GitHub main 변경 시 Vercel에서 자동 배포됩니다.

빌드는 페이지·CSS가 참조하는 파일과 폰트 라이선스만 포함합니다. `evidence/` 원본 분석 자료와 미사용 자산은 웹 배포하지 않습니다. 이 저장소에는 PHP, API, 데이터베이스 및 실행 의존 패키지가 없습니다.

## 문의 UI

상단에서 법인 설립·법인 전환·세무 관리 중 하나를 고르면 분야에 맞는 문의창이 열립니다. 문의 내용을 화면에서 정리할 수 있으며, 명시적으로 복사를 누르면 클립보드에 복사합니다. **서버 접수·전송·브라우저 영구 저장 기능은 없습니다.** 창을 닫으면 입력과 결과가 지워집니다. 이전 버전의 `ceopartners-consultation` 로컬 초안은 내용을 읽지 않고 삭제합니다.
